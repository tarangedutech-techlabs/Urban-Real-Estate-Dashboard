# Urban-Real-Estate-Dashboard
Urban Real Estate Dashboard is a web-based application designed to manage and visualize urban property data, including projects, inventory, sales status, analytics, and role-based access for admins, managers, and agents.
The Urban Real Estate Dashboard is a web-based application designed to manage and visualize real estate data in urban environments. It provides an interactive interface for handling projects, property inventory, analytics, and inquiries with role-based access control for different users such as Admin, Manager.
## ✨ Features

- 🧑‍💼 **Role-Based Access**
  - Admin
  - Manager
  - Agent

- 🏢 **Project Management**
  - View and manage real estate projects
  - Track project status

- 📦 **Inventory Management**
  - Property availability tracking
  - Unit status overview

- 📊 **Analytics Dashboard**
  - Visual charts and graphs
  - Sales and property insights

- 📩 **Inquiry Management**
  - Customer inquiry tracking
  - Organized lead handling

- 🔐 **Login & Logout System**
  - Secure role switching
  - Session-based UI updates
